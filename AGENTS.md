# IM News publishing rules

IM News is an editorial news website, not a sales website.

- Never add sales links, photo-purchase links, gallery-shopping buttons or calls to buy photographs in news articles, homepage stories, section cards or news captions. This includes Fotop event-gallery links. Fotop may be used privately for fact-checking; source URLs in non-visible verification metadata are not sales calls to action.
- Retain factual reporting and exact photographer credits. Preserve supplied photographs and approved editorial layouts.
- Website publication and Instagram publication are separate operations. Publish the website first. Do not publish on Instagram until the user gives a separate Instagram command for that event.
- The user authorizes committing and publishing requested website work without asking again. Verify the deployment and live result before claiming publication.
- Check every changed HTML file for visible sales links before committing. Run the repository publishing validation and distinguish existing unrelated failures from new-event checks.
